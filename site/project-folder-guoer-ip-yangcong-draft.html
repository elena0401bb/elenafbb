画面中，老师站在黑板前讲解，过儿坐在课桌前听课。我通过老师与学生的关系组织课堂画面，让过儿以法考生的身份参与知识内容。

从内容判断到协作落地

围绕主题、素材与画面组织制作需求，分别对接视觉和视频环节。

  1. 确定选题

    选择本期要呈现的问题，明确内容主题。

  2. 选择老师素材

    围绕选题挑选相应的老师讲解素材，确定这期内容的基础。

  3. 构思与对接设计

    构思老师、过儿及课堂元素在画面中的呈现方式，将需求传达给设计同事。

  4. 对接剪辑制作

    与专门负责剪辑的同事对接，推动老师素材与画面方案形成视频内容。
